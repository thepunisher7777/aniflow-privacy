Política de privacidad de AniFlow

Última actualización: 1 de octubre de 2026

AniFlow es una extensión de navegador que mejora la experiencia de reproducción en servicios de streaming compatibles mediante funciones como saltar intros, reanudar la reproducción y pasar al siguiente episodio.

1. Datos que procesa AniFlow

Para proporcionar sus funciones, AniFlow puede procesar información visible de la página y del reproductor, incluyendo el título mostrado, el número de episodio, la URL de la página, el tiempo de reproducción, la duración del vídeo y la presencia de controles como “Saltar intro”, “Continuar” o “Siguiente episodio”.

2. Almacenamiento local

AniFlow puede guardar en el navegador preferencias, perfiles, favoritos, historial de reproducción, estadísticas de tiempo ahorrado, configuración de Smart Skip y datos de diagnóstico. Esta información se utiliza únicamente para proporcionar las funciones de la extensión.

3. Servicios externos

Cuando el usuario activa funciones avanzadas de detección de anime, AniFlow puede consultar servicios externos como Jikan y AniSkip para identificar una serie y obtener intervalos de opening, ending o recap. AniFlow no envía a estos servicios contraseñas, cookies de autenticación, tokens de sesión, información de pago ni el contenido del vídeo.

4. Venta y transferencia de datos

AniFlow no vende, alquila ni transfiere datos personales a redes publicitarias, corredores de datos ni terceros con fines publicitarios, crediticios o ajenos a la finalidad principal de la extensión.

5. Uso limitado

La información procesada por AniFlow se utiliza únicamente para proporcionar o mejorar las funciones visibles de reproducción solicitadas por el usuario.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

6. Contenido protegido y DRM

AniFlow no descarga vídeos, no descifra ni elude DRM, no evita paywalls, no evita inicios de sesión y no proporciona acceso a contenido que el usuario no pueda reproducir por sí mismo.

7. Cambios en esta política

Esta política puede actualizarse si cambian las funciones de AniFlow o los requisitos aplicables. La fecha de actualización se mostrará en esta página.

8. Contacto

Para cuestiones relacionadas con privacidad o soporte de AniFlow, puede utilizarse el correo de contacto del editor indicado en la ficha de Chrome Web Store.
